## What is WinBind?

WinBind is both a customization and productivity tool, that helps your workflow feel more balanced, candyeyed and productive, it starts feeling like... you.

You can do multiple things with WinBind, such as:

- Make KeyBinds and other productive shortcuts
- Steal Focus out of windows
- Make windows translucent
- Apply various style to windows
- Add more features to your usual windows than before
- Load Other Configurations at ONE shortcut
- Change theming for windows(useful if you have another .conf)

All of this is AT your power if you touch the *.conf* file and read the docs.

## Compile from Source Code

I have used MinGW's GCC. You can use the same.
In ```build.bat```, change the ``GXX`` to your GCC path. Or if GCC is in your path, remove the line.

This allows manual code compilation. Easy and Simple.

## How to install?

In the zip folder, run install.bat, ignore the warnings and continue. That's it.

It will be in:
```%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\```

The *.conf*, if wanted to be edited will be in:
```%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\winbind.conf```

You can use most prefrably VSCODE (or VSCODIUM), or if that is not possible, use Notepad itself to edit.

Any text editor will do the job.
